# 读懂数据剖析报告

`scripts/profile_data.py` 给出作图前的结构线索，不替代研究设计或统计分析。推荐从命令行显式传入已知角色：

```bash
python scripts/profile_data.py data.csv --group treatment --unit subject_id --time visit --value response
python scripts/profile_data.py data.csv --json > profile.json
```

`--group` 与 `--value` 可重复指定；`--value` 用于明确整数编码的连续测量列。`--unit` 是独立分析单位的标识列，`--time` 是时间或重复观测顺序列。若这些角色未知，先问研究者或查数据字典；不要从 `id`、`date` 等列名直接推断。

## 报告中的事实

| 区块 | 可以读出什么 | 不能据此断言什么 |
|---|---|---|
| Columns | 类型猜测、非缺失行数、描述统计、零值与负值 | 数字 ID 一定是连续变量；异常点一定错误 |
| Group structure | 各分组的观测行数 | 行数等于独立样本数 |
| Study design clues | 各组不同单位数、同单位多行、重复单位×时间组合 | 自动判定配对、交叉或技术重复设计 |
| Correlations | 连续列的描述性 Pearson 相关 | 因果关系、显著性、非线性关系不存在 |
| Chart suggestions | 根据数据形态的初步候选 | 已选择最适合论文论点的图 |

自动类型识别需要复核。浮点列即使观测值恰好为整数，也按连续值处理；少量取值的整型列可能是顺序量表、编码类别或测量值。手动指定分组、单位和时间列后，这些角色不会被当作响应变量推荐。

## 行数与独立单位数

一人多次访视、一件样本多次测量、一台设备多个运行，都会让行数大于独立单位数。报告会给出各组 `n_rows` 和 `n_units`；两者不同的时候，图上的 `n` 必须说明指的是哪一种。重复单位可能意味着配对、纵向、层级或技术重复，报告不会替研究者决定。

`Duplicate unit-time rows` 是同一单位和时间组合多行的数量。它可能是重复测量、技术重复、附加维度，或数据错误。先查数据字典，再决定聚合或保留。缺失的单位或时间值不会计入重复组合。

## 分布、缺失与坐标变换

IQR 离群值计数是查看数据的线索，不是删除规则。缺失率也不说明缺失机制。比较组别时，应查看响应变量在各组各时间点的可用数量，而不只看整个表的缺失率。

普通对数轴要求绘制值为正。报告列出每个连续变量的零值和负值；它们存在时应保留原尺度、分面，或采用有明确解释的变换。即使全部为正，跨多个数量级也只是考虑对数轴的理由，最终取决于变量意义和想表达的差异。

样本量阈值是显示原始点、箱线图和密度估计的实用提示，不是统计有效性的统一界线。样本少时直接显示点通常更诚实；箱线、小提琴和 KDE 是否有帮助还取决于分布和读者需要。

## 从报告到图

1. 核对列角色、单位、缺失编码和有效数据范围。
2. 核对分组的观测行数与独立单位数；若重复，决定是否需要配对点或个体轨迹。
3. 明确图要回答的问题，再按 [图型选择](chart_selection.md) 选图。
4. 任何聚合、变换或排除都在代码和图注中记录；误差线写明定义。
